# Safe Route Finder 🚀

## Problem
Finding safe routes considering traffic, crime, and crowd is difficult.

## Solution
This project provides AI-based safe route suggestions using backend logic.

## Features
- User route input (source & destination)
- AI-based route scoring
- Civic issue integration
- Safe vs alternative route

## Tech Stack
- Node.js
- Express
- MongoDB
